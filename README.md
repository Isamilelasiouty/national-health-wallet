# منظومة المحفظة الصحية القومية المشفرة للمريض
### National Secure Patient Health Wallet System — جمهورية مصر العربية

موقع عرض تقديمي تفاعلي كامل لمنظومة **«المحفظة الصحية القومية المشفرة للمريض»**، مبني بدقة تامة ومطابقة حرفية لوثيقة المعمارية الكاملة وتصميم الواجهات *(ملخص هيكل وشكل وصفحات المنصة v2)*.

---

## 🌟 الفلسفة التصميمية والمعمارية للمنظومة

- **تصفح أفقي سلس (Horizontal Navbar Architecture):** إلغاء القوائم الجانبية المزدحمة لصالح هيدر ثابت وناف بار أفقي فرعي يمنح الشاشة مساحة عرض كاملة لمحتوى الكشف والسجلات الطبية.
- **هوية بصرية طبية هادئة:** 
  - الخلفية العامة: `#F5F9F6` (أبيض نعناعي ناعم مريح للعين).
  - البطاقات والهيدر: `#FFFFFF` (أبيض نقي مع حدود خضراء وظلال ناعمة).
  - الأخضر الداكن: `#1B6B46` (اللون الأساسي للعناوين والأزرار التفاعلية).
  - درجات الأخضر للبوابات: `#2D8259` (أخضر زمردي لبوابة الطبيب)، `#43936B` (أخضر مريمي لبوابة وزارة الصحة).
  - الأحمر مخصص حصرياً لبطاقة الطوارئ والتنبيهات الدوائية الحرجة.
- **تكامل لحظي مشفر:** ربط القطاعين الحكومي والخاص بسجل مشفر يملكه المريض، مع جلسات وصول مؤقتة (QR / OTP 6 أرقام لمدة 30 دقيقة) تتيح للمريض سحب الصلاحية فوراً بضغطة واحدة.
- **راحة العين وإمكانية الوصول (WCAG AA):** خط Cairo و Tajawal بأحجام خطوط مريحة (لا تقل عن 17px)، تباين ألوان معتمد، أهداف لمس 44px، دعم كامل للوضع الداكن (Dark Mode) بألوان زيتونية هادئة، ودعم إيقاف الأنيميشن لراحة المرضى وكبار السن (`prefers-reduced-motion`).
- **محاكي الهاتف الذكي («تجربة موبايل»):** زر تفاعلي يحول الموقع إلى إطار هاتف ذكي واقعي (390 × 820) بنوتش وحواف وأبعاد تطبيق موبايل كامل.

## 🏛️ أقسام وبوابات المنظومة

### 1) الصفحة الرئيسية والخدمات العامة (Landing Page & Public Tools)
- **الواجهة الافتتاحية:** رؤية المنظومة، خط نبض القلب (ECG Pulse)، والبطاقات الثلاث للبوابات.
- **نافذة تسجيل مريض جديد (Patient Registration Modal):** الاسم الرباعي، الرقم القومي (14 رقماً)، صلة القرابة، فصيلة الدم، المحافظة، الحساسية والأمراض المزمنة.
- **خدمة «تحقق من طبيبك» (Public Doctor Verification):** استعلام بالاسم أو رقم القيد النقابي للتحقق من اعتماد الطبيب رسمياً لمنع انتحال الصفة.
- **بطاقة الطوارئ الذكية (Emergency Card Modal):** تعرض لفرق الإسعاف البيانات المنقذة للحياة فقط مع اتصال مباشر بإسعاف مصر (123).

### 2) بوابة المريض والمرافق العائلي (Patient Portal — 5 تبويبات)
1. **لوحة المتابعة الرئيسية:** بطاقة رمز الجلسة المؤقت (QR / OTP) مع عد تنازلي 30 دقيقة وزر الإنهاء الفوري، بطاقة جرعات الأدوية اليوم وتأكيد الجرعة ✔، وبطاقة ملخص الحالة الحيوية.
2. **السجل الطبي الموحد:** جدول زمني للسجلات من المستشفيات الحكومية والخاصة مع فلتر تصنيف ذكي (الكل / روشتات / تحاليل / أشعات).
3. **أدويتي وإعدادات التنبيهات:** نموذج إضافة الأدوية يدوياً، لوحة إعدادات التنبيهات (في الموعد، قبل 10 أو 15 أو 30 دقيقة، SMS وواتساب، وإشعار المرافق)، وجدول الأدوية المفعلة مع تمييز «روشتة طبيب» و«إضافة شخصية».
4. **المرضى والمرافق العائلي:** بطاقات تفاعلية لكافة أفراد الأسرة (كبار السن والأطفال) مع زر فتح محفظة الفرد وإدارتها.
5. **سجل الخصوصية والوصول:** سجل رقابي يوثق بالدقيقة كل عملية دخول للطبيب ومنشأته وآلية المصادقة.

### 3) بوابة الطبيب والروشتة الإلكترونية (Doctor Portal — 4 تبويبات)
1. **شاشة الكشف والروشتة:** بوابة فتح الجلسة المؤقتة (Session Gate)، شريط التنبيه الطبي الحرج لحساسية البنسلين، التاريخ المرضي الموحد (العمود الأيمن)، ومحرر الروشتة الذكي المعتمد مع فحص تعارض الحساسية والتوقيع والترحيل اللحظي (العمود الأيسر).
2. **المحافظة وجهة العمل:** اختيار المحافظة من محافظات مصر الـ 27 وتحديد نوع المنشأة (حكومي / خاص / عيادة) واسمها ليُختم به التقرير.
3. **أرشيف الروشتات الصادرة:** سجل بالروشتات الموقعة رقمياً وحالة ترحيلها لمحفظة المريض.
4. **حالة الاعتماد والوثائق:** توثيق المستندات الثلاثة (الرقم القومي + شهادة التخرج + كارنيه النقابة).

### 4) بوابة وزارة الصحة والحوكمة (MoH Portal — 3 تبويبات)
1. **الترصد الوبائي اللحظي:** مؤشرات الأداء العليا KPIs *(مقدمة كأرقام توضيحية استرشادية لأغراض العرض التقديمي)* وجدول الإنذار المبكر (ICD-10) حسب المحافظات الأكثر تسجيلاً.
2. **مركز اعتماد الأطباء والحوكمة:** طابور مراجعة طلبات الأطباء ومطابقة المستندات مع أزرار القرار الرقابي الفوري (اعتماد ✔ / رفض ❌).
3. **المنشآت والتدقيق الأمني:** متابعة الربط المشفر اللحظي للمستشفيات والعيادات والمعامل على مستوى الجمهورية.

### 5) مسار التكامل الشامل (End-to-End Flow)
يوثق الدورة اللحظية: المريض يسجل ويولد الكود ⬅ الطبيب يفتح الجلسة ويفحص الحساسية ويوقع الروشتة ⬅ تُرحل الروشتة لمنبهات المريض وتظهر إحصائياتها المجهولة الهوية في ترصد الوزارة.

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية:** React 19 + TypeScript + Vite 8
- **التنسيق والأنيميشن:** Tailwind CSS v4 + كلاسات حركية بطيئة هادئة (400-800ms) + رسومات SVG مخصصة
- **الأيقونات والتصميم:** Lucide React (رموز طبية وهندسية نقية بدون أي أيقونات ذكاء اصطناعي)
- **دعم اللغة والاتجاه:** RTL كامل بنسبة 100% (`dir="rtl"`, `lang="ar"`) وخطوط Cairo و Tajawal

## 🚀 طريقة التشغيل محلياً

```bash
# 1. الدخول إلى مجلد المشروع
cd national-health-wallet

# 2. تثبيت الحزم والاعتماديات
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev

# 4. بناء نسخة الإنتاج النهائية واختبارها
npm run build
npm run preview
```
